## 关键术语

| 术语 | 定义 |
|------|------|
| N-back | 认知训练范式，判断当前刺激是否与N步前的刺激一致 |
| 记忆因子 (Factor) | 用于刺激的素材单元，如emoji、图片、音调 |
| 因子插件 (FactorPlugin) | 实现记忆因子接口的可插拔模块 |
| 游戏模式 (GameMode) | 一种特定的N-back玩法，如标准/双通道/空间/栅格 |
| 回合 (Turn) | 一次刺激呈现+用户判断的基本游戏单元 |
| 会话 (Session) | 一次完整的游戏过程，包含多个回合 |
| 刺激 (Stimulus) | 当前展示给玩家的记忆素材 |
| HUD | 游戏中的抬头显示信息（得分/进度/状态） |
