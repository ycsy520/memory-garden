# Android UI / UX Navigation Guideline

## 目标

为 `Memory Garden` 建立一套一致的返回与导航规范，避免同一语义在不同页面出现不同按钮形态，也避免把“返回上一层”和“回到某个明确页面”混成一种按钮。

本规范适用于 Web、PWA、Android Capacitor 壳。Android 作为上架目标时优先遵守本规范。

## 现状梳理

### A. 顶层返回按钮

这类按钮语义是“离开当前页，回到上一层或菜单”。

- `StatsScreen.jsx`
- `SettingsScreen.jsx`
- `LeaderboardScreen.jsx`
- `AchievementsScreen.jsx`
- `about/AboutLayout.jsx`

共同特征：

- 使用 `ArrowLeft`
- 使用 `ui-icon-btn ui-icon-btn-soft`
- 按钮本体只放图标，不放长文本
- 标题和副标题独立放在按钮右侧

这是当前项目里最稳定、最适合做统一标准的一类。

### B. 流程内上一步

这类按钮不是离开页面，而是在同一流程里回退一步。

- `MenuScreen.jsx` 的 `prevStep`
- `GuideScreen.jsx` 的 `prev`

共同特征：

- 使用 `ChevronLeft + 文本`
- 处于底部操作区，与“下一步/开始”并列
- 样式应属于次级操作按钮，而不是页面顶栏返回

这类按钮应继续保留文本，因为它表达的是“流程回退”，不是“页面返回”。

### C. 明确目标页的次级动作

这类按钮语义是“完成当前任务后，去某个明确目标页”。

- `FinishedScreen.jsx` 的 `回到花园`

共同特征：

- 处于结果页底部 CTA 区
- 是一个完整动作按钮，不是顶栏返回
- 可以保留文字，不必伪装成图标返回

这类按钮不应使用 `<--`、`←` 之类文本箭头。

## 统一规范

### 1. 顶层返回

适用场景：

- 设置页
- 统计页
- 排行榜
- 收藏页
- 关于页
- 菜单页中的“退出三步引导，回到花园”
- 游戏引导遮罩中的“退出当前训练”

规则：

- 统一使用 `ArrowLeft`
- 按钮形态统一为 `ui-icon-btn ui-icon-btn-soft`
- 按钮里不放“返回”“回到花园”“返回菜单”等长文本
- 具体目标通过 `aria-label` 表达
- 应放在页面顶部左侧，优先参与正常布局；仅在遮罩/覆盖层中允许绝对定位

### 2. 流程内上一步

适用场景：

- 向导页
- 教学页
- 多步骤表单

规则：

- 使用 `ChevronLeft + 文本`
- 统一使用次级按钮样式，如 `ui-btn-neutral`
- 放在底部操作区
- 不与顶层返回共用同一视觉语义

### 3. 结果页返回目标

适用场景：

- 训练结束页
- 成功页
- 完成页

规则：

- 可以保留明确文案，如“回到花园”
- 作为次级 CTA 出现在底部操作区
- 不使用文本箭头字符
- 可使用语义图标，但不使用“返回箭头”图标

## Android 规范判断

## 需要遵守的部分

这项目不需要机械地做成纯 Material 3 官方模板，但需要遵守 Android 用户已经形成的核心预期：

- 顶层返回要清晰、可预期
- 返回图标不要混用字符箭头
- 最小点击区域建议不低于 `48dp`
- 返回语义要一致，不能一会儿是图标、一会儿是大胶囊文字按钮
- 不要让顶部按钮遮挡正文、步骤条、状态栏区域

## 不必机械照搬的部分

作为一个有品牌气质的轻游戏/训练产品，你不需要把所有页面都做成标准安卓原生列表页：

- 不必强行使用标准 AppBar 样板
- 不必所有页面都改成纯 Material 配色
- 不必把所有按钮都做成安卓系统默认样式
- 不必为了“像安卓”而牺牲现有花园主题视觉

结论：

- **要遵守的是交互语义和触控规范**
- **不必照搬的是视觉皮肤**

## 当前项目的 Android UI / UX 结论

### 已经比较好的部分

- 主次按钮层级清楚
- 卡片、圆角、留白系统较统一
- 主要流程是移动端优先
- 文案可读性整体不错

### 当前最需要收敛的部分

- 返回按钮语义不统一
- 个别页面曾出现文本箭头
- 个别顶部返回按钮使用特殊大胶囊样式，偏离主流页面标准
- 全局最小点击尺寸原先为 `44px`，更适合 Web，Android 建议提升到 `48px`

## 本次落地决策

- 顶层返回统一为图标返回
- 流程内上一步继续保留“箭头 + 文本”
- 结果页“回到花园”继续作为次级 CTA 存在
- 全局最小点击尺寸提升到 `48px`
