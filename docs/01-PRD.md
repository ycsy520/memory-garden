## 1. 产品概述

### 1.1 产品名称

记忆小花园 (Memory Garden)

### 1.2 一句话描述

一款以N-back认知训练为核心、以温馨花园为主题的多端记忆训练游戏。

### 1.3 产品愿景

成为最友好的记忆训练工具——让老年人也能轻松使用，让年轻人在愉悦中锻炼工作记忆，并通过持续的科学训练帮助用户延缓认知衰退。

### 1.4 核心价值主张

- **老年友好**: 大字、大按钮、慢节奏、温暖叙事
- **科学有效**: 基于经实证验证的N-back认知训练范式
- **渐进增强**: 从简单的1-back到复杂的栅格N-back，平滑提升
- **多端一致**: Web → PWA → iOS/Android，体验无缝衔接

## 2. 目标用户

### 2.1 用户画像

| 画像 | 描述 | 核心诉求 |
|------|------|----------|
| 银发族 | 60+岁，手机使用不熟练，有轻度记忆衰退 | 简单易用、大字大按钮、温馨氛围 |
| 健康关注者 | 30-50岁，关注脑健康，希望预防认知衰退 | 科学有效、数据追踪、成就感 |
| 年轻人 | 18-30岁，喜欢游戏化体验，追求挑战 | 丰富玩法、竞技排行榜、分享 |
| 临床场景 | 认知康复辅助工具 | 可配置参数、数据导出、专业报表 |

### 2.2 用户场景

1. **奶奶的日常训练**: 每天下午，奶奶打开手机，花5分钟在花园里散步，辨认花朵。大字和慢节奏让她不感到压力。
2. **通勤脑力热身**: 上班族在地铁上打开游戏，完成一次双N-back挑战，然后查看统计数据。
3. **朋友间的记忆比拼**: 两个人分别完成挑战，分享成绩卡片到微信，比比谁的记忆力更好。
4. **康复师的辅助工具**: 认知康复师根据患者情况配置难度参数，导出训练数据做追踪分析。

## 4. 用户体验原则

### 4.1 设计原则 (不可违背)

1. **永远可玩**: 任何情况下核心游戏不崩溃、不白屏
2. **老年友好**: 最小触摸目标44px，最小字号16px，满足WCAG-AA
3. **渐进增强**: 基础功能离线可用，高级功能在线增量
4. **数据安全**: 用户数据永远不丢，跨版本兼容迁移

### 4.2 情感设计基调

- 色彩: 暖色调、自然系 (米白、鼠尾草绿、暖灰)
- 字体: 衬线体为主 (Georgia / Noto Serif SC)
- 动画: 柔和、缓慢、呼吸感 (支持prefers-reduced-motion关闭)
- 叙事: 奶奶的花园，花朵盛开，记忆回归
