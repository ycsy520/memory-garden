# Changelog

本文档记录 `Memory Garden` 已完成并确认落地的版本变更。

遵循版本规则：

- `MAJOR`：不兼容架构变更
- `MINOR`：新功能，向后兼容
- `PATCH`：问题修复与细节优化

---

## v5.2.0 - 2026-07-08

### 新增

- 接入 Supabase P0 后端能力：匿名登录、邮箱 OTP 登录、云端同步、离线队列、账户注销。
- 设置页增加账号状态卡片，支持同步、退出登录、注销账户、导出数据、清除数据。
- 新增关于与合规页面：
  - 免责声明
  - 隐私政策
  - 使用条款
  - N-back 科学介绍
- 新增关于页统一布局与设置页入口。
- 补齐三语翻译资源，覆盖账号系统与关于页面内容。

### 变更

- 对齐后端锚点文档与路线图，明确 P0 已完成状态。
- 设置页中的危险操作布局调整，注销账户按钮与常规操作分离，降低误触风险。

### 修复

- 修复 Chrome 下 PWA 无法显示安装选项的问题，补齐 PNG 图标与 manifest 兼容配置。
- 修复首页首次加载时横向线条闪现问题，移除首页与菜单页重复入场动画。
